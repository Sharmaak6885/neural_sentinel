Help Center

Support guidance for using the website, admin dashboard, and analysis tools.

Use this page to help visitors and team members understand how to work with the platform.

Getting Started

Open the homepage for public visitors, use the blog page for published content, and use the admin page to manage posts, contacts, and analysis history.

Website Analysis

The built-in analysis feature is passive. It reviews public page headers, metadata, forms, links, and keyword visibility. It does not perform exploit attempts or aggressive scanning.

Need Help?

Update the email and social links in config.js so visitors can contact you directly from the footer.
